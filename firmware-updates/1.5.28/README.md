# ELINK BWR 1.5.28 大字日历

本测试版适用于 DA14585 五触点 250 × 122 黑白红屏。配套网页为 1.1.29，设备版本标识为 `9ee31968`。在网页加载在线固件并手动确认 OTA。升级后选择「日历界面 → 日历主题 → 大字日历」，再应用到所选屏幕。

| 版式 | 画面 | 预览 |
| --- | --- | --- |
| B 左月右日 | 78 像素红色月份栏，右侧大号日期 | ![B](../../page-large-b.png) |
| D 红白等宽横排 | 每半屏 125 像素，数字与「月」「日」并排 | ![D](../../page-large-d.png) |
| F 双页台历 | 两张等宽卡片，红色页眉和黑色数字 | ![F](../../page-large-f.png) |

设备按已校准的本地时间在午夜的分钟回调更新日期。手机断开后仍可换日。首次上电或完全断电后需要重新校时。日历以实际日期变化触发，忙碌时可在下一次分钟回调补刷。

## 文件与验证

[OTA 升级包](../../firmware/elink-bwr-1.5.28.elink-update.json) 内的应用为 64,953 字节。应用 SHA-256 为 `c52e2dc89f7efd3c175137059a46f2c50f40cdb862ba1bbd096f1b564012801b`，OTA JSON 的 SHA-256 为 `b96cadcf8c2825650e087a2e2f592d5c5ca6cc5f25df2db8284746f51631a939`。

两次构建的 OTA 逐字节一致。Cortex-M0 指令仿真将三款版式在闰年 366 天的 1,098 帧与定稿图逐像素比对。通过原生选页命令和分钟入口验证了午夜、跨年、闰日、中午、两种校时命令及两个 OTA 区的字形读取。网页的 117 项 Node 测试通过。上述验证在模拟硬件上运行，真机 OTA、显影和过夜走时仍待实测。

## 固件源码

`overlay` 保存此次构建相对仓库内 `windows-manager` 源码快照的固件、字形生成器、依赖差异和回归测试。在配有项目基线镜像及 Zig 0.13.0 的 2.13 寸工作区覆盖同名源码，运行 `runtime/venv/Scripts/python.exe source/firmware/build.py --version 1.5.28 --output build/firmware-1.5.28`。构建器校验基线哈希及各代码区边界。数字与汉字来自 Noto Sans SC Medium，许可见 [FONT-LICENSE.txt](FONT-LICENSE.txt)。

日历的 44 个原生点阵字形和排版记录占用 OTA 应用尾部的 4,925 字节。设备从匹配当前固件标识的有效应用区读取，显示时不写 Flash。保留的运行时装载区仍为 3,240 字节。选页命令为 `9C 04/05/06`，状态模式为 `9/10/11`，状态包第 27 字节（从 0 起算）的位 7 表示支持大字日历。
