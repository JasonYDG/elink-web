# 大字日历配色 · 固件 1.5.31

在 Web 1.1.32 的「日历界面」中选择「日历样式」，再用「日期数字颜色」选择黑色或红色。四款大字日历都支持切换，默认黑色。颜色只用于表示几号的大数字。

| 样式 | 黑色 | 红色 |
| --- | --- | --- |
| 月份侧栏 | ![黑色日期](../../page-large-b.png) | ![红色日期](../../page-large-b-red.png) |
| 月日对半 | ![黑色日期](../../page-large-d.png) | ![红色日期](../../page-large-d-red.png) |
| 双页台历 | ![黑色日期](../../page-large-f.png) | ![红色日期](../../page-large-f-red.png) |
| 英文月与星期 | ![黑色日期](../../page-large-en-1.5.31.png) | ![红色日期](../../page-large-en-1.5.31-red.png) |

英文月份和星期整体向上移动了 12 像素。两行间距为 22 像素，上下留白分别为 31 和 32 像素。校时后可关闭网页并断开蓝牙，设备按当地时间在午夜换日，继续使用所选样式和颜色。完全断电后需重新校时。

## 设备与验证

适用于 DA14585 五触点 250 × 122 黑白红屏。固件标识为 `f9a128cd`。[蓝牙 OTA 升级包](../../firmware/elink-bwr-1.5.31.elink-update.json)

固件指令仿真已核对八种样式与配色组合在闰年 366 天的 2,928 帧，并验证跨午夜和屏幕忙碌后的补刷。浏览器验证覆盖六个平级菜单项、八张预览和移动端布局。实体设备的 OTA、过夜走时与显影待实测。

## 协议与源码

原有黑字选页命令为 `9C 04–07`，显示模式为 9–12。红字选页命令为 `9C 08–0B`，显示模式为 13–16。状态包第 27 字节的位 5 表示支持红色日期数字。在 [1.5.30](../1.5.30/) 的源码基础上覆盖本目录的 `overlay/`，再运行 `runtime/venv/Scripts/python.exe source/firmware/build.py --version 1.5.31 --output build/firmware-1.5.31`。
