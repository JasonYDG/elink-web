# ELINK Manager V1.5.2

更新任务汇总预览与固件版本识别。标题和时间采用18px红色Noto Sans SC Black，名称16px黑色；状态与日期统一右对齐。三条以内24px行距，四条20px行距，最多显示四条，超出显示项数。任务名称72px内显示，长名称省略；完整内容仍在到点提醒页显示。

离线提醒、重复、检查周期和持续时间沿用V1.5.0功能；A6大字名称沿用V1.5.1格式。已有A6日程升级后直接显示，无需重新保存。旧A5日程保留，重新保存后才使用16px名称。已有提醒时间和内容不自动修改。

保留原管理数据库、设备、模板和任务历史。先升级…91:A7一台，取得实物确认后再升级其他屏幕。到点提醒页、时钟及日历布局保持原样；默认时钟每5分钟对齐更新。
