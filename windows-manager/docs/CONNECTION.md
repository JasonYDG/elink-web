# 无按键标签的连接

1.0.3默认持续可发现，芯片仍在广播之间休眠；CPU、射频和LED无需常开。连接断开后立即重新广播，不因断开重画时钟或二维码。屏幕刷新频率与蓝牙连接方式分别设置。

启动Start.cmd，关闭其他手机或网页的连接，扫描ELINK-BWR-732dfd。也可登记地址18:BC:5A:6B:91:A7并读取状态。固件ID应与包清单相符，界面保留的旧记录不是实时在线证明。

在“刷新与省电”选择“持续可发现”，点击应用并读回验证，这会覆盖以前保存在管理端的定时窗口。旧1.0.1/1.0.2不能接受持续模式，先OTA升级或保留定时窗口。

可选“定时开放连接”：接收间隔1–240分钟、窗口10–120秒。窗口外暂时搜不到，已登记设备的后台任务会等待窗口；无按键仍有下一次连接机会。控制延迟增加，省电程度须量电流确认。断电后恢复持续可发现，后台发送内容时恢复已保存设置。

每台设备只允许一个未完成任务。等待任务可在任务记录取消，运行中的传图和OTA不盲目重复提交。日志可暂停实时更新，后台任务继续。自定义三色图片始终全刷，快速时钟仍属实验。

BUSY异常约90秒后关闭面板电源并返回错误4，显示代次不增加。下一次操作重新初始化面板；这一恢复不会记成显示成功。若仍花屏，保存回执和照片，检查刷新时供电。空载电压与灯亮不能证明电源正常。

默认持续模式仍长期搜不到时，先关闭其他控制端、检查蓝牙适配器和供电。芯片不能启动时才按FLASHING.md有线恢复。LED不是可靠连接指示，续航需要本板电流测量。
