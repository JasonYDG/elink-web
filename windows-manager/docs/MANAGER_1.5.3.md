# 管理端 V1.5.3：操作互斥与顶部进度

本次只升级 Windows 管理端，屏幕固件继续使用 V1.5.2 / ID `3bbf1f31`，不需要为此刷写设备。

当前屏幕操作固定在页面最前面，切到图片、提醒或历史页后仍可看到目标屏幕、执行阶段、进度及结果。任务排队、等待连接、读取、传图、清屏及刷新确认期间，设备相关控制统一锁定，避免重复点击产生冲突。

进度以后台状态为准：没有完成回执时不显示100%，也不解锁。校时和设置若触发刷新，也须等屏幕BUSY结束。失败或结果未知会明确保留，重新读取/核对后再决定后续操作；完成仅表示软件/设备回执，仍需观察实物画面。

一次选择多块屏幕仍可批量提交，后台依次处理整组。已有未完成组时，另一个网页或直接API请求也不能插入冲突操作。扫描与设备任务互斥。

顶部和任务记录保留“取消等待”；已经运行、正在写入或等待刷新完成的任务不能中途强制取消。尚未派发、没有旧设备记录的提醒可在顶部立即取消，其余提醒仍走设备确认取消流程。

操作锁定时可以切换页面查看进度、历史回执及备份数据。刷新页面会重新读取后台状态，不能绕过锁定；网络异常时不把陈旧的空闲状态当成任务已经完成。

验证记录保存在交付包 evidence 和本项目 `backup/2026-10-18/operation-lock`。本轮不声称修复所有无线掉线或完成真实光学验收。
