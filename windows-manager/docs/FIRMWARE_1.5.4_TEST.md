# 1.5.4 固件测试说明

2026-10-18，DA14585五测试点、250×122黑白红屏专用。此版是单图布局、大包接收和只读Flash诊断测试版，尚未完成设备图库与离线多图轮播。管理端1.5.3及生产交付指针保持不变。

## 本版能测试什么

- 原有时钟、月历、提醒、普通图片及其蓝牙命令保留。旧17B图片像素包继续有效，新上限128B；8000B帧需要63个128B像素包。设备刷屏耗时不因此缩短，实际包长还受连接MTU限制。
- 图片日历：上传一张图片后用 `9C 03` 进入，状态模式为6。左166×122保留图片，x166分隔，右侧显示年/月、45px日号、星期、农历及下一个节气名称。节气算法沿用现有月历；年/月和农历分别使用12px字体，星期14px。
- 已校时后，图片日历跨日由设备刷新右侧，左侧像素保持不变。未经校时、没有完整上传图片或正在刷屏时拒绝进入。切回时钟/月历后再次进入需重新上传图片；完全掉电不保留图片，提醒发生后也不承诺恢复照片。
- `BC` 返回16B诊断：`EFD1`、版本1、像素包上限128、原生90h两字节Flash ID（小端），再给出0x40000及0x7FFFC各4B样本。复用已验证原生唤醒、90h ID和读取函数，不新增擦除、写入或解锁命令；这些样本不能单独认定物理容量。

图库保存选项、多图播放列表、相对计时和换电池自动恢复仍未开放。现有网页正常上传继续使用17B包；新功能通过下文项目内测试脚本验证，未改动正在另行维护的HTML后台。

## 安装：Windows管理端蓝牙OTA

GitHub Pages发布的独立网页版ELINK Web 1.0.2不提供OTA，不能在那里导入此包。这里的升级入口仅指Windows管理端1.5.3；启动本机已有的 `F:\AI\2.13-Elink\releases\1.5.3-candidate\Start.cmd`，它会打开带Python后台的本地网页。两者不是同一个管理端。

保留 `firmware-test/20261018-512k.bin` 备份。先退出SmartSnippets的连接并让屏幕重新运行原有1.5.2应用；关闭其他占用该屏的蓝牙连接。

在Windows管理端选择一台测试屏幕，在“设备与显示”下方的“蓝牙固件升级”区导入测试包中的 `elink-bwr-1.5.4.elink-update.json`，核对版本和目标后点击“开始蓝牙OTA”。沿用已有OTA上传、全量读回、最后提交和新启动核对流程。成功后状态固件ID应为 `d78aa415`，开机页显示V1.5.4。

这是应用OTA文件，不能交给SmartSnippets当作偏移0的SPI文件。测试交付不含整片SPI刷写镜像，不需要整片擦除或改动烧录助手。原启动扇区、设备配置及原生蓝牙/面板代码不在本次功能变更范围内。若OTA结果不明确，先重新读取版本与状态，不盲目重复提交。

## 项目内手动测试

以下命令依赖本项目已有Python环境和源码，只在用户明确执行后连接指定MAC；不会自动扫描并挑选设备。先关闭管理端对该屏的连接。将 `AA:BB:CC:DD:EE:FF` 换成实际测试屏完整MAC。

```powershell
Set-Location F:\AI\2.13-Elink
runtime/venv/Scripts/python.exe -X utf8 source/tools/test_photo_calendar_device.py --address AA:BB:CC:DD:EE:FF --firmware-id d78aa415
```

上面仅诊断读取；把输出的Flash ID和两个样本留作容量核对。显示图片日历：

```powershell
runtime/venv/Scripts/python.exe -X utf8 source/tools/test_photo_calendar_device.py --address AA:BB:CC:DD:EE:FF --firmware-id d78aa415 --photo source/web/image/01-sunrise-lake.png
```

脚本按电脑当前本地时间校时，将照片裁切成166×122后生成8000B帧，根据MTU选择17–128B像素包，逐包检查位置，再提交并进入图片日历；会报告实际包长。脚本收到完成状态不代表光学效果已验收。断线、位置不符或超时会停止，不自动重发提交。若需验证跨日，请保持运行至次日并检查左图未变。

返回现有时钟：

```powershell
runtime/venv/Scripts/python.exe -X utf8 source/tools/test_photo_calendar_device.py --address AA:BB:CC:DD:EE:FF --firmware-id d78aa415 --clock
```

回退应用可使用测试包内 `rollback/elink-bwr-1.5.2.elink-update.json`；不要把全片备份当作普通应用包或擦掉现有提醒数据。
