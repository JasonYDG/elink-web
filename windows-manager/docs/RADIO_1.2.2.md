# V1.2.2 广播间隔候选包

适用 DA14585 五测试点、2.13 寸黑白红 250×122 标签。基于 V1.2.1，仅调整固定广播间隔及版本标识、开机页版本文字。

- 广播最小、最大间隔均为 1636 个 0.625 ms 时隙，即 1022.5 ms；三个广播信道均保留。
- 固件 ID：`28768807`。默认持续可连接，沿用原有广播事件之间的扩展休眠和断开后恢复路径。
- OTA 选择 `firmware/elink-bwr-1.2.2.elink-update.json`；有线恢复选择 `firmware/elink-bwr-1.2.2-spi.bin`，偏移 0，写入后 Verify。不要向 OTP 写入，也不要将完整 SPI 镜像用于 OTA。

回归：旧 V1.2.1 在新增间隔断言上失败（实际 3200/3200）；V1.2.2 完整 50 项测试通过，包含原生广播命令构造、镜像 CRC、OTA 全量回读及启动标识提交。测试执行实际 Thumb 代码，射频与面板光学效果仍需实机验证。

已知未解决：用户报告的周期性广播静默、Windows GATT Unreachable、时钟切页后的可见残影。本候选不宣称修复这些问题。管理端完成回执仅确认控制器 BUSY 结束，不能证明屏幕无残影。

1022.5 ms 属于苹果列出的较长广播间隔之一；其完整建议还包括初期快速广播。本候选只调整固定间隔，不包含双速广播。
来源：https://developer.apple.com/library/archive/qa/qa1931/_index.html

诊断脚本 `build/diagnostics/adv_rate.py` 统计电脑实际接收次数，无法单独证明空口没有发射；`watch_status.py` 通过 0x93 查询状态，不写图像或固件。独立诊断时应停止管理端设备任务并释放手机连接。
