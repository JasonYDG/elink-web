# 1.5.7：屏幕离线图库与清晰图片日历

本地 Windows 管理端和 2.13 寸 DA14585 五测试点 BWR 250×122 固件配套测试版。固件 ID `c028427e`，应用 60028B。本轮没有连接或刷写实体屏幕。

## 使用

1. 先退出旧管理端，再运行本包 Start.cmd。原有 AppData/Local/ElinkManager/data 数据继续使用。
2. 在蓝牙固件升级处选择 `firmware/elink-bwr-1.5.7.elink-update.json`，只先升级测试屏。读取状态确认 1.5.7。
3. 勾选屏幕，选择“图片”或“日历 → 图片日历”。开启图库上方的“保存到屏幕图库”。
4. 单击内置图多选，最多4张；电脑图片库中自己的图片可点“加入当前图片”。列表编号就是播放顺序，移除后重新加入可放到末尾。
5. 图片日历可点击列表中的图片名，分别左右拖动照片或调滑杆。预览使用166列图片加84列日期栏；每张取景位置会写入设备配置。
6. 设定每小时、2/6/12小时、每天、每2天、每周，或1–168个整小时，点击“保存图库并开始轮播”。等待最上层操作弹窗显示完成。
7. 完成后可以关闭程序、断开手机和电脑。设备从 Flash 读图并自行刷新，不依靠 Windows 计划任务。只有1张时保存并显示，不按间隔重复刷同一张；图片日历仍会跨天更新日期。

“保存到电脑”仅管理本机图片；“保存到屏幕图库”才占用屏幕 Flash。未勾选时仍是原来的单图上传，会停止该屏幕旧轮播而保留已存图片。选择默认、时钟、普通月历、任务汇总也会持久停止轮播。停止按钮会读回确认；重新应用图库会替换旧播放列表。两种图片模式共用同一套图库，不能同时各放一套4张。

## 画面与传输

日期改为原生44像素数字；中文用有 SIL OFL 许可的 Noto Sans SC Medium，年月、星期、农历、节气重新排版。节气当天显示“今日”，其他日期显示下一节气及“几天后”。没有从4.2寸固件复制专有字体。

每张8000B，支持128B像素包时为63包，兼容17B旧包。写入图库时不逐张刷新，全部CRC32校验后只显示第一张。每次实际换图继续使用原有完整清屏及刷新流程；未测量真实蓝牙吞吐、刷屏速度或电流，不能承诺达到4.2寸速度。

## 断电与提醒

图库和播放间隔保存在 Flash；正常睡眠保留计数，完全断电后从第1张重新开始计时，首个分钟节拍恢复显示。换图不要求先校时。图片日历的日期在未校时期间留空，校时后恢复完整日历并从第1张继续。时钟和提醒的绝对日期仍需重新校时。

提醒优先显示，设置了持续时间的提醒结束后恢复同一张图库图片，换图间隔重新计时。无限时提醒需由用户切换页面。BUSY、OTA 和提醒期间暂停轮播计时；间隔以分钟节拍计，未测实机长期误差。

新图库先写非活动图像区，验证后再交替提交元数据；最后写有效标志。更新中断时保留已提交的完整图库。首次初始化要求专用72KiB区域全为FF；未知非空内容不会自动擦除。首次空配置写入若恰好断电且没有任何有效配置，重试会安全拒绝，须保留读回信息后单独处理该区，不能全片擦除。

## 资源与底层保护

借鉴4.2方案的共享像素槽、压缩字库和设备计时。原66像素时钟字形数据从3820B槽压缩为1248B，逐像素还原，腾出2572B应用代码区（包含共用字形解码器）。仍使用同一套8000B帧缓冲，不另分配4张图片RAM；图库状态96B放在已有RAM扩展尾部。

五个C区余量：.clock=118B, .reminder_extra=8B, .product=28B, .reminder=8B, .album=36B，合计198B。这是当前链接布局的余量，不是整颗Flash余量。原来的“162B”只适用于1.5.5四个固定C区，不能作为相册实现不了的结论。

新增图库 Flash 范围仅 `[0x40000,0x52000)`，72KiB。原生ID必须为A1/12；完整备份和既有诊断对应FM25Q04 512KiB。低256KiB保持原有布局，日程区不占用。SPI驱动的高地址发送另用原指令测试，完整发送24位地址，没有高区回卷。

启动/复位、蓝牙和射频初始化、原生Flash及屏幕驱动、面板波形、OTP/MAC/校准、原生堆栈边界保持原字节。变化限于应用代码、应用字库、应用调用地址和固件标识；分钟入口继续调用原native clock_print，再执行应用轮播节拍。RAM装载长度仍为3240B。

详细布局和协议见 [OFFLINE_ALBUM_1.5.7.md](OFFLINE_ALBUM_1.5.7.md)。应用OTA包不包含整片覆盖镜像。回退1.5.5应用不会清除高区图库，旧应用也不会使用它。
