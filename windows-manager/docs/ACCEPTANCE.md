# 标签验收记录

状态：候选，已完成的真实 OTA、RAM 与 BUSY 验证见 VALIDATION_REPORT.md；光学、电流及长期项目仍待实测。记录实际日期、固件 SHA256/ID、电源、电池型号和蓝牙适配器，不能以模拟执行结果代替。

1. 有线完整镜像 Verify；断电重启显示 ELINK 自有开机页，扫描 ELINK-BWR 名称、读取 ELK1 与清单 ID 一致。记录 LED 是否熄灭。
2. 默认全刷：日期、农历、黑白红公告、水平/竖直一像素线、长文本和大时间。照片观察缺笔、残影、红层错误、边缘裁切。
3. 默认持续可发现，连续20次独立扫描/连接/读取/断开，断开后立即可重新发现；后台运行24小时，不出现长时间连接中、协议拒绝或不明自动复位。
4. 可选定时窗口：设5分钟接收间隔、20秒窗口，记录至少三个开放窗口；窗口外时钟仍运行，再改回持续可发现并读回窗口值0。
5. 设 3 分钟时钟全刷，至少观察 10 次更新时间；快速模式留为实验，不作为三色默认放行条件。
6. 自定义内容发送后放置 30 分钟，画面不被原生时钟覆盖；恢复时钟、再发送。开启计划，断电上电后同内容应恢复；不变内容的检查任务不重复全刷。
7. 固件区版本不同的 `.elink-update.json` 做一次真实 OTA：逐字节读回、提交、重连、ID 核对、同步时间。再做一次上传中人为断线，断电重启旧版本可工作，新区未提交。不要在首次未知供电条件下测试提交瞬间断电。
8. 电流表量 LED 关闭后待机、广播、连接、全刷电流；以这些数值和实际电池容量估算续航。空载电压 >3V 不能代替刷新时的供电测量。
9. 在测试板模拟BUSY卡住，约90秒后返回错误4、显示代次不增加、面板断电且蓝牙仍可操作。不要在正常标签上短接不明面板引脚。

如果任何项失败：保存管理端 SQLite 备份、任务回执、包清单和照片；使用已验证基线回退。只有补齐上述实测，才可把 hardware_tested 改为 true 并形成下一份验收交付清单。
