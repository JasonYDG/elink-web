# ELINK BWR V1.3.1

适用 DA14585 五测试点、IL3897、2.13 寸三色 250×122。本版不调整蓝牙广播间隔、面板复位、BUSY 超时与三色 LUT；保留 1.2.2 的 1022.5ms 广播及两阶段清屏。

- 默认页：版本号红色，大写 V；版本与完整 MAC 用“-”连接；左边竖线、标题、规格和横线对齐。
- 点阵字体：小字使用 Fusion Pixel 原生12px，正文使用 Unifont 原生16px，大字只作整数倍放大，时钟大数字保留原厂66px。中文不作偏移假粗体。
- 月历：周末色块、红底白字今日、年份、生肖、农历、节气；六行月份使用12px日期，不裁掉最后一行。
- 时钟默认每5分钟更新，按钟面分钟05/10/15等对齐；可选15分钟、整点、每分钟。显式选择页面会立即显示，之后按整点计划更新。每分钟提醒影响屏幕寿命和待机时间。
- 可选本地或荷兰时间；底部中间标“荷兰”。管理端使用 IANA Europe/Amsterdam 数据，设备离线按现行欧盟规则自动切换夏令时。年份范围2020–2051，未来法规变化需更新固件。

更新周期指屏幕画面更新；设备持续计时，不需要每5分钟连一次蓝牙。设置保存在管理端和设备保留 RAM，完全断电后需由管理端重新应用。

蓝牙 OTA 使用 `elink-bwr-1.3.1.elink-update.json`；有线使用 `elink-bwr-1.3.1-spi.bin`，offset 0，Verify。只先升级一台试用，确认实物后再升级其他。SPI 镜像不能用于 OTA；不要操作 OTP。

构建检查字体、代码、状态和原厂时钟数字边界；OTA 写非活动区，全部读回一致后才提交启动标记。软件检查无法证明实际字形、残影消除或电流；这些仍需实物验收。

V1.3.1 相比1.3.0：BWR英文规格16px加粗；时钟底栏、月历星期和侧栏、公告底栏统一16px。月历侧栏加宽，闰月与六行日期均作边界检查。OTA重启后清理旧WinRT发现对象，后续任务重新扫描。
