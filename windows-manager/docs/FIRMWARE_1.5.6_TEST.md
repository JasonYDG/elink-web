# 2.13 寸图片日历字体测试固件 1.5.6

本包仅适用于现有 ELK1 应用OTA路径的 DA14585 黑白红250×122标签。固件ID为 `14271ec2`，应用大小60028B，SHA256：

`f235e8953e74c03264b9ae4db3bea14959cee2c3d71117d47f3774cba2d59e24`

使用配套1.5.6管理端的固件升级入口，选择 `elink-bwr-1.5.6.elink-update.json`，先在一块测试屏验证。回退应用位于 `rollback/elink-bwr-1.5.5.elink-update.json`。本包不含整片SPI覆盖镜像，不使用整片擦除。

本版以原生44像素数字替换15像素放大3倍的日期，采用较轻的Noto Sans SC Medium中文，重新排列年月、星期、农历及一行节气倒计时。实际像素见 `photo-calendar-preview.png`，完整变更见配套管理端说明。

与1.5.5比较，仅应用绘制代码、应用字库和固件标识发生变化。启动/复位、蓝牙射频、原生Flash和屏幕驱动、波形、OTA扩展及原生66像素时钟字体保持逐字节一致；分区和内存边界保持不变。校验记录见 `protected-region-check.json`。本次没有设备写入，没有更改OTP、MAC或校准信息。

四个固定C代码区剩余166 / 16 / 76 / 8B，合计266B；它们分散且不能直接视为任意功能可用空间。44像素十个数字压缩后633B，存于现有应用字库范围。字体许可和来源随包附带。

软件仿真不代表实机验收完成。待测试：实际笔画清晰度、跨天日历更新、原时钟/月历/提醒切换、蓝牙与OTA回退。离线多图轮播仍未实现；本版不会写入尚未核实的图库分区。
