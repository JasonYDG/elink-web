# V1.2.0 修复与交付

适用 DA14585 五测试点、IL3897 黑白红 250×122 标签。应用 60040 字节，完整 SPI 241664 字节，固件 ID **38d70f9e**。应用 SHA256：838024e3175368c533fdfc576fd593297adb61ac48bba899102245358db754a5。

- 四屏及更多标签采用勾选、批量页面选择与逐台回执。默认、时钟、日历、公告在一起；旧设备按能力拒绝新版页面，升级后可选。单台设置/OTA 显示独立目标 MAC。
- 默认页可重新进入，保留时间及显示代次，不被分钟时钟覆盖。内置页面成功切换后停用该标签旧公告计划；任何未完成设备操作都会阻止同标签计划排队。
- 日历月份左上、电量右上，红底白字高亮日期，右栏年份/农历/节气。默认页、时钟、日历电池左侧均加蓝牙符号；公告内容由模板决定，管理端提供图像/文字自定义，不强行覆盖用户图片。
- 默认页 ELINK/BWR/分隔线/V 版本左边对齐。BWR 14 像素，底栏移高；完整 MAC 不加 MAC/READY 标签。农历两个字用完整 16 像素字形，底部 y=98，避免顶部缺笔。
- 整页轻快刷从 UPDATE_FAST 改为原项目每分钟使用的 UPDATE_FLY。保持原生 BW 脉冲/时序，红像素组合不驱动；每 10 次、小时/日期/外围或红层变化全刷。实验分钟局刷不作为默认推荐。
- 保留共用复位等待、90 秒 BUSY 失败恢复、广播之间休眠、持续可发现、低电平 LED 的高电平关闭及唤醒关闭钩子。
- 双区 OTA 在提交前比对完整数据，重启后校验新 ID；读取 FF01 过期短状态时重新发查询，不将旧值当成功。

使用配套 V1.2.0 管理端，OTA 选择 .elink-update.json。有线安装选择 -spi.bin，偏移 0，按 FLASHING.md 擦/写/Verify。完整 SPI 不能用于 OTA，不烧 OTP。

已完成结果见 VALIDATION_REPORT.md。原三色初始化与复位修复已有用户光学确认；本版快刷效果不能由 BUSY 回执或像素 RAM 推断，需实际照片确认。当前包保留候选标记，避免把电流和长期项目写成已测。
