# ELINK BWR V1.4.0 离线任务提醒

适用于当前DA14585五测试点、2.13寸黑白红250×122标签。保持V1.3.5的Noto Sans SC Black像素大小、页面布局、每5分钟对齐更新、1022.5ms广播参数、LED极性及唤醒处理、面板复位/BUSY超时、清屏两阶段与快刷波形。

新增8槽独立Flash日程区0x26000..0x35FFF，管理端限7条待提醒、预留一槽用于安全编辑。该区域在钉住原始SPI和先前实机Flash备份中均为空白，构建断言防止OTA应用区越界。日程帧写入不改变屏幕当前内容，CRC与全量读回核对后最后启用；目标刷新完成后才写“已触发”。未提交写入3次分钟检查后解除占用，CRC不一致或BUSY超时不会报成功。日程和帧存Flash，分钟计时仍需标签保持供电；完全断电后须再次校时。

只裁掉内置字库未使用的字符，保留所有实际显示字形，腾出有界代码区；12/14/15/18px字形和原生66px数字不缩放。新增代码和160B保留状态由链接/构建边界断言约束，OTA仍仅写非活动应用区，存储日程不受OTA擦写影响。布局预览除版本号外保持既有设计。

OTA：firmware/elink-bwr-1.4.0.elink-update.json；有线：firmware/elink-bwr-1.4.0-spi.bin，偏移0，241664字节，完成Verify后重启。有线全镜像会清除离线日程，OTA会保留；不操作OTP。固件标识及SHA256见manifest.json。

先升级...91:A7一台，取得启动/重连及独立离线提醒证据后，请用户确认实物再升级其他屏幕。光学及真实耗电未由模拟器验证。
