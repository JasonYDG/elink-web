# 2.13 寸离线图库固件 1.5.7 测试包

适用 DA14585 五测试点、BWR 250×122 标签。ID `c028427e`，应用60028B，SHA256 `7674f52b6ba8de12f1afd730ebfc989b4115c06307ab7cf1fc417b8b3613739b`。

使用配套1.5.7管理端的蓝牙OTA入口选择 `elink-bwr-1.5.7.elink-update.json`。先测试一台；不要全片擦除，不要把应用镜像直接写到SPI偏移0。本包只提供应用OTA升级文件和1.5.5应用回退。

加入4张离线图库，整屏图片和图片日历共用，间隔1小时至7天。图库占高Flash `[0x40000,0x52000)`，校验型号及空白/已识别配置后才写入。压缩现有66像素数字腾出应用代码，时钟像素保持不变；右侧日历使用44像素原生日期及授权中文字体。

硬件驱动及底层信息未改，保护区逐字节对照随包附带；仅应用绘制、存储逻辑、字库和应用调用地址变化。软件测试包括实际Thumb代码、NOR模型及原生SPI高地址字节，仍未刷实机。

完整使用方法和断电边界见配套管理端文档。首次初始化中断可能因没有有效配置而拒绝重试，不能用全片擦除解决。更新已有图库时旧图库保留到新配置提交。

停止轮播后可选择 `rollback/elink-bwr-1.5.5.elink-update.json` 回退应用。回退不删除图库，不恢复绝对时间。请实测光学、续航、掉电和OTA稳定性。
