# ELINK BWR V1.3.5

时钟顶部日期从 13 增至 14 像素，星期与 AM/PM 从 12 增至 14 像素，继续使用 Noto Sans SC Black。星期最后一字向右移动 2 像素，避免变大后的字形重叠。分割线改为黑色，从 y=20 移至 y=22，并延伸至 x=249，覆盖包括 100% 在内的电量字段右端；大时间数字、底栏、其他页面布局保持原样。

新增字符仍使用原生字库格式，时钟顶栏共 597 字节。产品代码起点向后移动 256 字节，链接器继续检查代码不覆盖保留 UI 状态。蓝牙参数、OTA 机制、5 分钟对齐刷新默认值、快刷波形和红层保护均不改动。软件检查与实际光学清晰度分别记录。

OTA 使用 firmware/elink-bwr-1.3.5.elink-update.json；有线使用 firmware/elink-bwr-1.3.5-spi.bin，偏移 0，241664 字节，并 Verify。完整 SPI 文件不可用于 OTA，不操作 OTP。固件 ID 及 SHA256 见 manifest.json。

V1.3.5 管理端保留 V1.3.4 修订 2 的选择对象修复，预览图更新为新固件。先升级 …91:A7 一台，用户确认实物后再升级其余屏幕；模拟帧、BUSY 和 OTA 校验不能替代光学及续航确认。

公告发送前读取目标标签 FF02 的两字节电压（mV），按固件相同的电压曲线估算电量，填入已排队图片的状态区域，任务快照与 SHA256 随实际发送帧更新。正文、日期及裁切不会重新生成；纯图片模板不叠加状态图标。读取失败显示 --%，不使用固定 100% 或其他设备的数据。管理端显示电压及估算值，回执保留数据来源和读取时间；设备没有提供 ADC 采样时间。模板预览未绑定设备时显示 --%，设计示意图 67% 明确标为示例。

2026-10-06 五台只读实测电压 3.009 / 3.044 / 3.023 / 3.076 / 3.026V，均落在原有公式的 100% 档。该数字是电压估算，不是库仑计量或精确剩余容量；本次未更改电池曲线，未测量续航。
