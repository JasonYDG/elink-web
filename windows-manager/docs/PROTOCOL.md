# ELK1 协议 1

服务 FF00，读写控制 FF01，电压 FF02。完整 UUID 使用 `0000xxxx-0000-1000-8000-00805f9b34fb`。写入带响应，主机每次读取状态先发送93，等待任务队列更新再读；周期时钟也会更新 FF01，故需处理过期值。

| 命令 | 参数 | 行为 |
|---|---|---|
|91|原生12字节校时包|1.1.0 验证日期/时分秒/农历范围；初始化时间，月历模式保留，其他模式转时钟|
|93|无|返回32字节 ELK1 状态|
|94|mode,every|1.1.1：0全刷/1整页快刷/2实验分钟局刷；间隔1..60|
|95|transfer_id:u16, sum16:u16|开始8000字节传图|
|96|offset:u16, payload≤17B|严格顺序写入；跨层位置已验证|
|97|transfer_id:u16|计数与校验和一致后提交全刷|
|98|无|兼容恢复时钟；新版管理端统一使用9C0选择新版时钟|
|99|clock_minutes,adv_minutes,window_seconds|1..60、1..240、0持续广播或10..120秒窗口；0需1.0.3|
|9A|offset:u16|1.0.3：只读128字节实际像素RAM，offset<8000；末块按色层有效长度截取|
|9B|无|1.0.3：只读128字节原生屏幕配置，诊断尺寸与GPIO|
|9C|view:u8|1.2.0：0新版时钟/1月历/2默认页；0/1要求已校时，2保留已有校时；均要求空闲、全刷|
|9D|无|1.1.0：8字节 `ELUI,01,flags,00,00`；flags位0月历/位1分钟局刷/位2粗体时钟；1.1.1增加位3整页快刷/位4静默校时；1.2.0增加位5可重新选择默认页；旧ELK1忽略时仍返回旧状态|
|9E|同91的时间字段，12字节|1.1.1静默校时，切到静态模式不重画时钟，供公告首次发送使用；忙时拒绝|
|9F|zone:u8,summer:u8|1.3.0：0本地/1荷兰；summer=0/1，local仅允许0；忙或传图中拒绝；仅在读回能力bit6后使用，设置后须用91/9E同步相应的钟面时间|
|A0|保留1字节,size:u16|应用须至少 0xE2F4 字节、最多65535字节；实际长度见包清单；擦非活动区，屏幕忙时拒绝|
|A2/A3|保留7字节,128B|原生 OTA 页前/后半；消息必须136B|
|A1|offset:u16|读回非活动 OTA 区的128B|
|A4|无|最后提交有效标记并触发原生软件复位|
|A5|无|不提交新镜像，复位回旧活动区|

状态布局：0..3=`ELK1`；4协议1；5模式；6全刷间隔；7显示0时钟/1接收/2静态/3月历/4默认页；8忙；9错误0无/1非法/2忙/3传图过期/4BUSY超时；10接收u16；12传输ID；14累加sum16；16目标sum16；18刷新代次u16；20快速计数；21窗口秒（0持续）；22广播间隔；23广播计数；24时钟刷新分钟；25刷新计数；26失联传图分钟或刷新BUSY轮询计数；27时间已初始化；28..31固件ID。多字节数值均 little endian。

1.1.0 模式1/2都仅允许经过参考校验的分钟局刷，并受 every 间隔上限保护。小时、日期或窗口外内容/红层变化都全刷；模板、开机、失败恢复也全刷。月历只在日期变化或显式刷新时全刷。

1.1.1模式1恢复原生整页快刷，模式2仍为分钟局刷。两者均受全刷上限保护，换小时、日期、其他内容或红层变化全刷。静默校时后不会在传图前出现一次时钟页；显式91/98可以恢复时钟。

显示数据共8000字节，先BW4000，再红层4000。逻辑250×122，native122×250，每行16字节；pos=(249-x)*16+y//8，mask=128>>(y%8)。黑/红像素均清BW位，红另置红层位。无灰阶/抗锯齿传输。

图片提交后，只有 BUSY 结束且代次变化才确认设备刷新完成；这不证明光学显示正确。提交前未完成数据不会自动显示，失联3分钟解除传图占用；提交后断线记未知，不自动重复提交。

1.0.3 的 BUSY 上限为225次、每次40个SDK定时单位，约90秒；超时沿原生流程关闭面板供电并恢复芯片休眠，错误4、显示代次不递增。允许再次传图，仍须检查电源与面板。持续广播绕过停止计时器，不调用非法的零延迟 app_easy_timer；远端断开后立即重新广播，且不因此重画时钟。

OTA 包是 host 验证的 SHA256 应用镜像、版本和板型声明；不能推断为签名认证。页零先保留标记FF，所有128字节块包括填充完整比对后才发A4。后台检查新固件ID而不是只看BLE连接建立；同ID不重复写。SPI布局沿用基线：应用区2000/14000，product38000，屏幕配置39000/3A000。

1.2.0 模式1选择原时钟 UPDATE_FLY BW 波形并保护红像素；模式2仍为实验分钟局刷。内置页面切换完成后管理端暂停旧公告计划；排队中的任意设备操作均阻止该标签自动公告插队。默认页4不被分钟回调重画，99控制的时钟周期仍保留。

1.2.1 保持协议与能力位不变。从时钟退出或快刷历史后的全刷包含白色清屏与目标画面两个阶段；两段完成才递增一次代次。各段仍约90秒BUSY超时；后台提交后的等待上限190秒，清屏失败不会报成功。

1.3.0：ELUI flags bit6 表示荷兰时钟；状态27改为位字段：bit0时间已初始化、bit1荷兰模式、bit2当前夏令时。旧状态只设置bit0，兼容解码。默认刷新间隔5分钟，按钟面分钟 modulo interval 对齐；显式页面选择立即刷新。3月最后一个星期日02→03、10月最后一个星期日03→02，bit2阻止重复回拨。9F只设置时区标志；主机随后同步正确时区的日期/时分与农历。


V1.3.5 管理端读取 FF02 的2字节 little-endian 电压（mV），逆推原生ADC比例并使用与内置页面相同的估算曲线。设备没有电量计或采样时间字段，battery_read_at 是主机读取时间。公告状态区域在每台实际连接后填入其电量，重新记录8000B帧、PNG、SHA256及电压回执；纯图片不改动。未绑定模板预览显示 --%，设计示例值标明67%，读电压失败不沿用历史百分比。协议命令及能力位不增加。


V1.4.0 ELUI bit7 表示独立离线提醒。ELK1 状态长度不变，错误5表示提醒像素 CRC 失败。存储 8 个 8192B 槽，管理端最多7条待提醒，留一槽用于先写新、后取消旧的原子编辑。SPI 0x26000..0x35FFF 是钉住原始镜像中已确认空白的独立日程区，远离2000/14000两应用区与38000产品/面板配置。每槽192B头+8000B帧；NOR状态 FF无效、FE待触发、FC已完成刷新、F8取消或校验/刷新错误。magic/token/due/CRC在0/4/8/12，状态在16。所有写操作分256B页边界并等待完成；全量像素读回核对后最后提交FE。BWR格式与现有传图相同。

| 命令 | 参数 | 行为 |
|---|---|---|
|B0|slot:u8,token:u32,due_utc:u32,crc32:u32|仅空闲；擦除非FE槽，开始写入，未激活；日期2020..2051|
|B1|offset:u16,payload≤17B|严格顺序写入独立Flash；不改当前画面|
|B2|token:u32|8000B且CRC正确；重新读取Flash校验，最后提交FE|
|B3|utc_offset:i32|本地钟面的UTC偏移秒，范围±50400；荷兰模式仍按固件夏令时位计算；用于离线UTC到期比较|
|B4|slot:u8|返回24B ERM1查询，见下文|
|B5|slot:u8,token:u32|匹配当前token才取消；读回F8后主机才完成删除/完成日程|
|B6|无|终止未提交写入；部分像素保持无效，不擦其他槽|
|B7|slot:u8,offset:u16|读回日程像素最多128B，末块按8000B截短|

B4：0..3 ERM1；4协议1；5槽0..7；6状态；7 bit0正在写，高4位最近实际完成槽+1（0未知）；8 token u32；12 due UTC u32；16 CRC32 u32；20已写字节u16；22当前写槽；23 UTC偏移已同步0/1。主机还须检查ELK1的时间已初始化。校时路径会同步B3。完全断电后时钟丢失，Flash日程保留，但须再校时才执行；OTA保留日程区，升级后管理端自动校时。提醒按原生每分钟回调执行，与时钟画面5分钟更新周期无关；当前屏幕忙时延迟到下一次分钟检查。提醒屏幕电量在触发时使用原生ADC绘制；主机再次读状态时从真实像素RAM取得缩略图。FC只在目标BUSY完成后写入，不把入库成功当成画面已显示。


## V1.5.0 日程扩展

ELUI 第 6 字节 bit0 表示今日汇总、重复和持续时间能力；原 B4 的 24B 槽信息保持兼容。新增 B8 + offset:u8 + 数据（最多18B）顺序写入 156B 元数据，位于槽头 20..175；marker=A5、星期掩码（周日 bit0）、检查间隔 1/5/15/60、持续分钟 0..120、UTC偏移 i32、96×12 标题位图 144B，最后是前152B CRC32。B2 在帧与完整元数据均验证后才启用。无元数据的旧槽按一次性、每分钟检查、持续显示处理。

B9（无参数）切换今日汇总，要求已校时及 B3 偏移；BA + slot:u8 + offset:u16 读回元数据，每块最多128B；BB + slot:u8 返回20B：ERM2、mask、check、duration、Flash marker、next_due:u32、last_due:u32、UTC偏移:i32。last_due=0/1 表示尚未完成本轮提醒。重复槽每次成功后仍为 FE；一次性槽在 BUSY 完成后为 FC。页面模式5为汇总，模式2为到点提醒。持续时间从 BUSY 完成后计数；到期返回汇总。电脑关闭不影响原生分钟回调。

### V1.5.1 汇总大字兼容

ELUI byte6 bit1 表示 `reminder_large_text`，须与bit0一起设置。B8策略仍156B，CRC仍覆盖前152B；A5标题为96×12，A6标题为72×16，都使用144B单色位图，帧起始偏移192及每槽8192B不变。BB byte7允许A5/A6/FF。新管理端只对声明大字能力的标签使用A6；旧槽和旧标签保持A5路径。日程执行和OTA区没有变化。
