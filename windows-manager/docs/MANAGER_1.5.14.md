# Manager 1.5.14 / Web 1.1.1 / Firmware 1.5.12

修复升级后默认页、网页时钟示意与实际图库画面不一致。

- 设备卡片仅显示已核对的像素或发送记录，读图失败不再代用时钟、日历示意图。旧固件未校时的模式0标为“画面待确认”。
- 读取等待设备空闲，以最终模式、画面代次、传输号和固件标识核对8000字节显存。读图时自动换页，最多重新读取一次；蓝牙中断保留错误并沿用最多三次的手动读取重连策略。提交写入后的未知结果仍不重放。
- 固件1.5.12仅把应用初始页面标记0改为4，与ELINK开机画面对应。保留已启用的图库，开机后仍由设备自己的分钟入口恢复第一张；读取信息不会清空、停用或重新上传图库。
- 操作弹窗保留一个操作标题、当前步骤和必要的进度/取消按钮；去除重复标题、提示、时间与设备信息。批量操作保留设备身份，失败仍可查看错误。

先运行旧服务包的 `Stop.cmd`，再运行新包的 `Start.cmd`。关闭网页不会停止服务。数据继续保存在原用户目录。

回归覆盖真实编译后的Thumb路径、旧1.5.2服务发现、读图中换页/断连、像素关联、网页事务和新解压冻结包。新固件与1.5.11的所有执行指令、字形、RAM和存储边界保持相同；仅版本文字、固件ID和初始页面数据不同。没有修改启动、射频、蓝牙底层、屏幕驱动、波形、MAC或校准数据。

现场只读确认1.5.11仍保存四张启用图库，读回第一张与“湖畔鸟居”原始8000B完全相同。Windows首次9A00中断的底层原因尚未确认；新版本通过检测变化和有限恢复处理，不声称已消除所有蓝牙中断。1.5.12尚未写入实体屏幕，光学、掉电和长期稳定性待实测。
