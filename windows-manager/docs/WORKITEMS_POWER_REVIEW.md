# 省电建议核对（2026-10-06）

WORKITEMS_POWER.md 是建议清单，其电流、每次刷新电荷及续航数字未经这四块标签实测。不能把模型计算天数当作续航承诺。

V1.2.1 本次落实：原生 GAPM 共享间隔从1100槽（687.5ms）改为3200槽（2000ms），三个广播频道保留，可连接并持续可发现；原生 extended sleep保持，操作后后台断开，LED活动与唤醒钩子保持高电平。1分钟时钟仍是耗电最密集的使用方式，已有四台设置不悄悄更改；界面提示长期展示优先日历/公告、未设置的表单推荐10分钟，应用后才改变标签。

实际 Thumb 测试核对默认/公告/日历60分钟节拍不重复刷新；日历跨日只发一次全刷。含红预览统计红色像素并提示。新增清屏阶段只用于从时钟退出或快刷历史后的全刷；日历跨日不增加清屏，避免静态页额外耗电。

大包传图、夜间免刷、低电量保护与广播携带状态保留为后续建议，尚未实现。刷屏期间休眠保持现有已稳定流程；此路径曾出现失联和花屏，待电流实测确认收益后再独立验证。

需实测：熄灯待机、电流脉冲、快刷、清屏加目标全刷、完整传图、真实电池型号与连接方式。没有实测前，不给出“可运行多少天”的确定数字。电量百分比仍是电压估计。

WI-1 目前只提供界面建议，未实现“新登记标签默认读回10分钟”，因此不能将它标为全部完成。WI-2 续航计算也尚未加入：新清屏加目标的两段成本必须计入，且尚无本板电流数据。

清单中的“2秒在苹果兼容建议范围内”需修正：[Apple QA1931](https://developer.apple.com/library/archive/qa/qa1931/_index.html) 列出的发现优化间隔没有2秒。本版2秒是针对当前Windows管理端的取舍，不宣称苹果设备发现时延已验证。[Renesas睡眠教程](https://lpccs-docs.renesas.com/Tutorial_SDK6/sleep_mode.html) 支持在广播事件间启用休眠；本板整体电流仍不能直接套用芯片实验室数值。
