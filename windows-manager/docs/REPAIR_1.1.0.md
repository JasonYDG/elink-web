# ELINK BWR 1.1.0

适用本次 DA14585 五测试点、IL3897 黑白红 250×122 标签。固件 ID 以 `firmware/manifest.json` 为准。

## 使用

运行配套 1.1.0 管理端，在升级处选择 `elink-bwr-1.1.0.elink-update.json`。完整 SPI 镜像仅用于有线安装。

开机页底栏按顺序显示版本、设备自己的完整 MAC、电池图标和百分比，无 MAC 标签、无 READY。ELINK、BWR、分隔线与版本号的实际像素左缘统一为 x=21，MAC从 x=56 起，电池从 x=198 起；最宽地址和100%均保留间隔。电量沿用原程序的 ADC 电压估算曲线，尚未采样显示 `--%`。三路 LED 继续在显示及每次唤醒锁存前设为高电平。

“恢复设备时钟”启用独立时钟：12 小时制、AM/PM、日期星期、农历日期及年份、下个节气倒计时（当天显示“今日”）。节气采用基线2020–2051年的近似表与同一计算规则，不是新增天文算法。小字换成微软雅黑粗体的纯色位图；大数字保留清晰的原字库，实际字形位于 y=27..92，中间区纵向居中，底栏从 y=100 起。构建检查全部页面用字，缺字会停止构建，避免原生找不到字形时进入调试异常。

“设备月历”显示本月完整日期网格和今日红色标记，设备跨日自己更新，无需电脑每日推送。支持 2020–2051 年、闰年和六行月份。首次使用需校时；断电后需重新校时和选择显示模式。模板中的日历仍是公告/安排模板，与设备月历分开。

## 刷新

默认每次全刷。选择“只局刷分钟，定期全刷”后，仅在同一小时、日期、其余黑白内容和整层红色内容未改变，而且前次 BUSY 正常完成时局刷。

首次显示、强制校时、换小时、AM/PM 切换、跨日、其他元素变化、换页面、定制图片、错误恢复及达到配置的全刷间隔，都全刷。所有快速模式都受全刷间隔上限保护。局刷列为实验选项，须实机观察红色保持与残影。

窗口为逻辑 x=138..240、y=24..95，原生 gate=9..111、source byte=3..11。每次上电初始化控制器并重载完整画面，再向控制器红层 RAM 写保护掩码；不改保留的真实红层。LUT2/3 为中性波形，窗口外像素不套用黑白刷新波形。gate scan start=9，MUX=103 行。依据 [IL3897 原厂数据手册](https://cursedhardware.github.io/epd-driver-ic/IL3897.pdf) 实现，不以 RAM 写入范围冒充驱动范围；最终效果以真实面板为准。

BUSY 约 90 秒超时后关闭面板供电、返回错误 4，不提交显示代次或可局刷参考，下一次全刷恢复。蓝牙默认持续可发现，窗口设置仍可选，不依赖按键唤醒。

## 构建与验证

复用已验证的 SPI、复位、BLE 与 OTA 路径。新增 Cortex-M0 C 模块放入旧时钟函数及本板不用的低分辨率数字字库区域，32 字节运行状态放在后者末尾的保留 RAM。构建限制代码、字库、状态与 BLE 堆边界；禁止隐式 data/bss 初始化。

开发使用 `runtime/venv/Scripts/python.exe`、官方 Zig 0.13.0 和本机微软雅黑字体。下载来源与校验值在 `runtime/tools/zig-toolchain.json`；编译器未全局安装。生成字库和各代码段 SHA256 记录在清单中。

ELK1 32 字节状态兼容，新增 9D 显示能力与 9C 页面选择。管理端检测能力后才开放月历，旧固件仍可用原功能。OTA 保留非活动区上传、全量回读、最后提交、新 ID 核对。

软件验证执行生成的 Thumb 机器码、原生字库及绘图/格式化函数；GPIO、SPI、ROM 算术边界使用模型。实机、电流和长期测试的完成情况见 `VALIDATION_REPORT.md`，不以软件通过代替光学验收。
