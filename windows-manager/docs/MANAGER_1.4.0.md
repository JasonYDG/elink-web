# ELINK Manager V1.4.0

图片和任务提醒分开管理。图片页保留上传、拖动裁切、缩放、方向旋转、原图保存、同ID编辑及删除；首页的图片选项只发送已保存图片。原公告入口改为任务提醒，不再展示旧公告模板编辑器；旧模板与任务快照仍保留在数据备份及历史记录中。

任务提醒输入标题、内容、日期时间并选择屏幕。后台提前连接标签，把完整8000B画面写入独立Flash日程区，逐块全量读回，再启用。列表显示“已写入屏幕 · 离线待提醒”后可关闭电脑，标签自己按分钟检查日程并切换画面。等待写入、失败和未知状态都不等于离线提醒已启用；可用“重试 / 核对”恢复中断任务。每台最多7条待提醒，支持一次性日程；不提供未请求的重复规则。

需要 V1.4.0 固件。完全断电后日程Flash仍在，RTC时间丢失，须重新校时；读取状态后会提示“需要重新校时”，用对应日程的“校准标签时间”按钮恢复，静态画面保持。只关闭电脑而标签电池继续供电不影响执行。荷兰时钟按UTC时刻判断到期，兼容秋季重复小时；日程输入使用电脑本机时区。触发时保留提醒画面直到下一次主动切换，多个同分钟日程逐分钟按到期先后显示。屏幕BUSY时顺延到下一次检查。提醒不附带蜂鸣器或手机通知。

删除、标为完成或编辑已经写入的提醒，需要连接标签读回确认；取消等待任务并不能撤销已存入标签的提醒。编辑先验证新槽，再取消旧槽，最多预留8个物理槽中的一个用于替换。列表保存编辑仍使用原ID。取下电池的标签需供电并连接后才能取消日程。取消登记前须先清除标签内已启用的日程。

预览无目标电量时显示 --%。实际提醒触发时使用标签当前原生ADC估算电量，读取状态后从实际像素RAM更新缩略图，不把事先生成的帧当成实物证明。电量为电压估算，非精确剩余容量。

顶部排队提示跟踪本次提交的任务ID。任务成功、失败、取消或进入未知状态后自动消失；其他任务不会让旧提示常驻，后出现的错误也不会被旧任务完成误清除。执行动态和历史回执保持独立。

数据目录保持 AppData/Local/ElinkManager/data；备份后升级程序，不覆盖登记的屏幕、图片及历史。固件先验证一台 ...91:A7，其他屏幕仍待用户确认后再升级。软件Thumb执行、Flash读回和BUSY回执不能替代实际光学及电池续航测量。
