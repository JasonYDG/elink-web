# 管理端 V1.3.6

本次仅更新 Windows 管理端，配套标签固件仍为 V1.3.5（85bba3ef），无需重新刷标签。

- 每块屏幕的卡片合并 MAC、显示状态、固件、电压估算电量和最近记录时间。
- 公告缩略图来自已确认任务的不可变像素快照，要求显示序号、传输 ID、固件 ID 与最近读到的设备状态一致。时钟、月历及默认页使用标明“界面示意”的缩略图，不能当作实时屏幕截图。没有读到的状态不推测为在线或已完成。
- 首页只在选择时钟时显示刷新与省电设置，选择公告时显示公告模板和更新计划。
- 执行动显示实际任务阶段、进度、等待/连接错误及更新时间；历史回执仍在任务记录中。实时进展不要求用户保持历史记录自动更新。
- R2：排队提示关联本次提交的任务，全部完成、失败或取消后在下一次状态轮询自动收起。等待任务继续显示，新出现的错误提示保留。
- 内容布局、文字与裁切变化自动生成实际像素预览，尚未上传图片时提供标明示意的图片布局。
- 载入编辑后保存更新原模板 ID；只有新建才增加模板。删除模板同时移除关联自动更新计划，不影响已排队任务的快照、历史回执及历史图片。
- 移除页面上被挤到右侧的字体授权说明，授权文件继续包含在交付包 legal/fonts 内。

升级前在线备份数据库，确认没有正在执行的设备写入，再停止旧管理端并启动新版。数据库只新增任务阶段字段，已有设备、设置、模板和任务不重建。
