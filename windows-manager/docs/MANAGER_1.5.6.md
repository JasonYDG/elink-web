# 1.5.6 图片日历字体与排版

本版配套 Windows 管理端和 2.13 寸 DA14585 应用固件。图片日历使用原生44像素大数字，替换原15像素点阵放大3倍的方式；中文与年月改用较轻的 Noto Sans SC Medium。右栏保持83像素可用宽度，依次显示年月、大日期、星期、农历和节气倒计时。节气当天显示“今日”，其他日期显示距离下一节气的天数。

250×122黑白红屏无法显示灰度抗锯齿。本版减少放大导致的三像素台阶和粗笔画粘连，预览按真实像素生成；仍需在实体屏幕确认细笔画的清晰程度。

## 使用

1. 退出旧管理程序，再运行本包 `Start.cmd`。用户数据库仍使用原有 AppData 路径，升级程序不清空模板或任务。
2. 先在一块测试屏 OTA 更新 `firmware/elink-bwr-1.5.6.elink-update.json`，读取状态确认固件 ID `14271ec2`。
3. 选择“日历 → 图片日历”，在功能选择下方挑选内置图片，左右调整取景，再应用到屏幕。

网页预览与固件使用同一字形和坐标。旧固件的普通页面继续兼容；新版图片日历入口要求1.5.6，避免预览与旧屏幕排版不一致。提交、校验及等待刷新完成仍由顶层操作弹窗展示。

## 字体与空间

12、14、18像素共享正文换为 Medium，因此时钟标题、月历标题和提醒摘要也会变轻；原15像素月历数字、66像素时钟数字及启动背景保留原样。44像素大日期仅使用十个数字，原始1088B，游程压缩后633B，放入应用字库区已有640B范围。

四个固定C区剩余空间为166 / 16 / 76 / 8B，合计266B，比1.5.5增加104B。这是分散的代码余量，不代表Flash总空闲量。没有移动原有代码区边界、堆栈或保留RAM边界，没有占用图库、提醒存储或OTA回退分区。

字体来自官方 Noto CJK 固定提交，许可为 SIL Open Font License 1.1，来源和文件校验值见 `source/fonts/preview-fonts.json`，许可随包附带。没有提取或复制4.2寸固件的专有字体资源。

## 验证与边界

实际Thumb执行测试覆盖1–31日数字、节气当天/两位天数、跨年、闰月、闰日，逐字节比对管理端预览与固件画面；保护区与1.5.5逐字节比较。最终回归、独立ZIP启动和静态视觉检查记录随交付包保存。

此包为待实机验证的候选版；没有执行刷机、实体光学或续航测试。离线多图图库与自动换图仍未实现，本次只改字体和排版。4.2寸硬件不可使用此固件。
