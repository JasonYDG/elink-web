任务提醒入口选择“显示今日任务汇总”可立即切换页面；添加、编辑或删除日程时，标签确认写入后也会切换到汇总。可查看今天的任务时间、标题和“待提醒 / 已提醒”；“已提醒”仅表示画面刷新完成，不表示用户完成事项。汇总任务名称最多显示 72px 宽，长名称会以省略号显示，完整文字仍保留在管理端及到点提醒页。

重复可选不重复、每天、工作日或自定义星期。检查可选到期分钟、每 5/15/60 分钟，持续可选 1/5/15/30/60/120 分钟或一直显示。默认检查每分钟、持续 5 分钟；较长检查周期会延迟到下个对齐检查点，前一条提醒持续期间也会排队。检查不等于刷屏，页面像素未变化不会刷新。

策略、完整提醒帧和汇总标题提前写入标签 Flash，并全量读回验证。列表显示“已写入屏幕 · 离线待提醒”后，电脑关闭也会触发及重复。离线汇总和重复需要 V1.5.0 或更新固件；大字汇总需要 V1.5.1。日程按输入时的固定 UTC 偏移执行，独立于时钟页的荷兰时间；夏令时改变或迁移时区后需重新保存日程。完全断电后须重新校时。

时钟本身仍在标签离线运行，默认每 5 分钟对齐更新。“应用到设备并读回验证”会校验表单并创建真实任务，按钮旁显示下发状态和回执。全刷间隔范围 1..60 次；以前填入 240 导致后台拒绝、没有任务的问题已改为就地校验。保存的非法旧值加载时限制在有效范围内，仍须主动应用才写入标签。
