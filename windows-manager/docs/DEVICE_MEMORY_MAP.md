# 2.13 屏设备空间全表：1.5.10

2026-10-19；DA14585，固件ID `fde89808`。32B就是32个字节：此前只指1.5.2的 `.product` 固定段余量，并非整颗芯片只剩32B。1.5.5四个C段总余量162B也不是硬件总余量。

1.5.7通过无损压缩已有66px数字，增加2572B应用段并实现离线图库。1.5.8分步写入后五个C段剩余162B；1.5.9调整图片日历、字库与应用计时后剩余198B，1.5.10小字加粗后仍为198B，分散且不能直接拼成任意功能预算。应用大小仍60028B，RAM扩展装载3240B和原生堆栈边界保持不变。构建代码并未使用全部512KiB。
