# 2.13 寸 1.5.5 应用固件测试包

适用于已运行本项目固件的 2.13 寸 DA14585 黑白红屏，配套 Windows 管理端 1.5.5。已确认的测试屏为 `18:BC:5A:6B:8A:B1`；本轮未自动连接或烧写设备。

1. 先退出旧管理程序，启动 `releases/1.5.5-candidate/Start.cmd`，确认页面显示 V1.5.5。
2. 只选择测试屏，读取状态；在“蓝牙固件升级”选择本目录的 `elink-bwr-1.5.5.elink-update.json`。
3. 等上传、逐块读回、提交和重启核对全部完成。再次读取状态应显示 **1.5.5 / 6c3279f4**。
4. 测试单图、图片日历、取景靠左/居中/靠右，核对实际画面。日历应显示年/月、大号日期、星期、农历和“节气 / 今日或 N 天后”。
5. 检查时钟、月历、提醒仍正常；查看图片任务记录中的传输、刷新及读回时间。等待刷新时弹框不能提前关闭，失败结果应保留待核对。

本包只含应用 OTA 升级文件，不含整片 SPI 覆盖文件。应用长度仍为 60028B；启动、蓝牙、面板、SPI/OTA 辅助代码相对1.5.4逐字节一致，区段地址及上限不变。`protected-region-check.json` 和 `comparison.json` 为离线比较证据；不能替代实机显示、续航和掉电验证。

图片日历在完整接收8000B并校验一致后，直接合成并提交一次刷新；普通图片协议保留。支持128B传图的连接仍是63个像素包。实际速度改善尚未实测，不承诺与4.2寸不同硬件相同。

**未实现：保存多图到屏幕，以及每小时/每天的离线图片轮换。** 四个C代码区余量26/16/76/44B，共162B且不连续，仅代表当前固定C区，不能据此判定轮播无法实现；布局和应用层压缩仍待验证。本版不通过占用底层、提醒或OTA恢复区解决空间不足。日历跨天更新已经存在，不能视为图片轮换。换电池仍需重新校时和发送图片。

回退文件在 `rollback/elink-bwr-1.5.4.elink-update.json`，通过相同应用OTA流程使用；回退后新版图片日历入口会要求升级1.5.5。保留原有全片备份，禁止把本应用文件当作整片固件写入。
