# 四功能模块拆分与空间对照

2026-10-18。范围：2.13 寸 DA14585 / IL3897 黑白红屏，固件拆分基线为 1.5.2-candidate / `3bbf1f31`。用户同期将网页管理端更新到1.5.3；其当前交付指针指向1.5.3-candidate，设备固件仍为1.5.2。本轮不回退该更新。

## 结果

四个现有功能已分到独立模块目录，并由构建端清单登记入口和源文件。公共调度、校时、屏幕刷新、蓝牙回复和 OTA 保留在公共核心。采用静态组合，不新增设备端函数指针表或插件加载器。

重建基线与当前交付镜像一致；模块化后的应用和 SPI 镜像又与该重建基线逐字节一致。模块拆分净开销 **0B**，没有腾出额外空间。应用仍为60028B，SPI镜像仍为241664B，固件ID仍为 `3bbf1f31`。源文件与 ELF 调试信息发生变化，因此 ELF 哈希不同是正常现象；设备镜像哈希未变。

| 执行区域 | 拆分前 | 拆分后 | 上限 | 剩余 |
|---|---:|---:|---:|---:|
| `.clock` | 852B | 852B | 1284B | 432B |
| `.reminder_extra` | 2656B | 2656B | 2724B | 68B |
| `.product` | 4428B | 4428B | 4460B | **32B** |
| `.reminder` | 1696B | 1696B | 2208B | 512B |
| 汇编扩展固定代码区 | 1232B | 1232B | 1232B | **0B** |
| 运行叠加区（含素材、状态、辅助代码） | 3240B | 3240B | 3392B | 152B |

这些区段不连续；运行叠加区还包含上述汇编代码，不能将两行大小重复累计。链接区段上限直接从现有链接脚本断言提取。

| 模块 | 当前可归属代码统计 | 统计边界 |
|---|---:|---|
| 时钟 | 1020B | 渲染、原分钟调度入口和页面选择函数；调度仍服务日历/提醒 |
| 日历 | 1076B | 月历绘制和反色辅助函数 |
| 提醒 | 4352B | 独立提醒 C 实现中最终保留的函数 |
| 图片 | 216B | begin/data/commit 汇编处理范围 |
| C 公共核心 | 2342B | 绘制原语、刷新、日期/时区和公共控制等最终保留的函数 |

函数统计不包含全部共享只读常量和对齐；它用于代码归属和后续预算，不等于独立插件包大小或删除该模块的净节省量。完整区段占用、详细符号和源文件哈希以 `build/firmware-modules/space-report.json` 为准。

## 验证边界

首轮完整回归执行71项，70项通过；唯一失败为HTTP测试仍在断言管理端1.5.2，而网页端同时更新为1.5.3。失败发生时进程已加载旧测试文件，原始日志予以保留。用户确认网页端更新完成后，使用新文件重跑受影响的17项后台、HTTP及提醒联动测试，全部通过（53.337秒）。没有把单独复测伪装成一次新的71项完整运行。

新增的3项模块检查在首轮均通过，覆盖实际编译入口与符号、源文件哈希、代码归属及链接区段统计、无效清单与重复/未登记汇编片段。比较工具另通过实际镜像一致、损坏镜像拒绝、过期空间报告拒绝三种检查。

本轮不连接蓝牙或串口、不烧写设备、不主动修改 `CURRENT_DELIVERY.json`，保留网页管理端更新后的1.5.3交付指针。新构建保留1.5.2固件版本，是因为设备字节完全相同，不是发布了新增功能。

相册、图库全片只读备份、新执行区布局、未校时相对计时、真实电流/光学/长期及掉电行为均不在本轮已实现范围。最终测试数量、完成状态及审查结论以退出检查为准。
