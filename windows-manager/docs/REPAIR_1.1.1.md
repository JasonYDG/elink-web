# ELINK BWR V1.1.1

适用本次 DA14585 五测试点、IL3897 黑白红 250×122 标签。升级后核对固件 ID 与 `firmware/manifest.json` 一致。管理端版本 1.1.1。

开机页使用大写 V。ELINK、BWR、横线与版本号的实际像素左缘均为 x=21。BWR 字号14，实际顶部66；横线83，底栏实际顶部89；横线上下各留5个空白像素。底栏依次为版本、设备自己的完整MAC、电池图标和电量，不显示MAC或READY标签。电量为基线ADC电压估算，尚未采样显示 `--%`。

时钟使用12小时制及AM/PM。日期、星期、农历日期和年份、节气倒计时采用粗体纯色位图；农历两个字再加厚，底栏上移2像素，完整字形与大数字分离。大数字实际范围 y=27..92。节气沿用基线2020–2051近似表，当天显示“今日”，不是精密天文计算。

设备月历左侧显示完整月份，今天红底白字；右侧显示公历年份、农历年份和下一节气。支持闰年、六行月份，跨日独立更新。完全断电后重新校时和选择模式。

## 刷新及公告

默认每次三色全刷。管理端新增“整页快刷，定期全刷”：分钟变化使用基线原生整页快速波形；首次显示、换小时/日期、其他元素或红层变化、错误恢复，以及达到全刷次数上限时执行三色全刷。测试标签设为每分钟刷新、每10次全刷、持续可发现。

1.1.0分钟局刷的软件与设备BUSY路径曾通过，但用户认为实机观感怪异，不能记为光学验收通过。保留为实验选项；仅此模式使用分钟窗口保护掩码及中性LUT2/3。切回整页快刷时恢复原始LUT，避免残留窗口配置。

发送公告首次校时使用9E命令，只初始化时间、不绘制时钟；接收及静态内容模式阻止分钟时钟重画。旧1.0.5在首次发送时可能先画原生时钟，需升级固件及管理端后使用此路径。显式“恢复设备时钟”仍能返回时钟。

## 保留的可靠性措施

LED三路低电平点亮，显示及每次唤醒锁存前设为高电平。默认持续广播，芯片在广播之间休眠；断开立即重新开放。BUSY约90秒超时关闭面板电源、报错误4，不提交虚假显示代次，下次操作重新初始化。

OTA向非活动区上传，全部字节回读匹配后才提交启动标记；重连核对新ID。完整SPI镜像只用于有线烧录，不能用于OTA，不操作OTP。所有代码、状态、字库和保留BLE边界由构建断言限制。

9D能力位：月历、分钟局刷、粗体时钟、整页时钟快刷、静默校时。旧固件不具备相应能力时管理端不开放新设置。

源码和开发工具说明见README，真实测试进度见VALIDATION_REPORT。RAM/BUSY回执不等于光学验收；LED电流、续航和24小时稳定性仍需实测。
