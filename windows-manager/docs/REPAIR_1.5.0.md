# ELINK BWR V1.5.0

适用 DA14585 五测试点、2.13 寸黑白红 250×122 标签。保留既有默认页、时钟和日历布局，Noto Sans SC Black 字库原尺寸、5 分钟对齐更新、1022.5ms 广播、LED 关灯、复位/BUSY 超时和 OTA 路径。

新增今日任务汇总页面（模式 5）。日程安装并验证后立即切换汇总；到期由标签原生分钟计时触发提醒画面，显示持续时间结束后返回汇总。汇总像素未变化时不启动面板刷新。每日及星期重复由设备独立计算，不依赖电脑后台，也不在每次重复时擦写 Flash。

8 个 8192B 物理槽仍限定在 Flash 0x26000..0x35FFF，管理端限 7 条启用日程，留一槽安全编辑。192B 槽头利用原空白空间加入策略和 96×12 标题位图，校验 CRC32 后才写 READY。旧 V1.4.0 一次性槽仍可触发；要显示标题、持续时间等新功能，需由管理端安全重新安装。编辑先写并核验新槽，再取消旧槽。

检查周期可选 1/5/15/60 分钟，按日程本地时区对齐；持续时间 1..120 分钟，0 表示保留直到下一条提醒或主动切页。同一时刻多个提醒依次显示，后者会因前者持续时间和面板 BUSY 顺延。重复采用日程固定 UTC 偏移，不自动调整夏令时；跨时区或夏令时变化须重新保存日程。

保留 RAM 状态移到 0x07fc8500（最多 256B），只裁剪 12px 字库未被调用的字形；各代码区由链接断言限定，应用镜像仍为 60028B。完全取下电池后 Flash 日程仍在，但必须重新校时；重复日程恢复到校时后的下一次，不补放错过的事件。电脑关闭而标签不断电时正常执行。

OTA 文件：firmware/elink-bwr-1.5.0.elink-update.json。有线全 SPI 镜像偏移 0，241664B，会清除日程；优先 OTA 保留日程。固件 ID 54937aa2，哈希见 manifest.json。不操作 OTP。先验证 …91:A7 一台，用户确认实物后再升级其余四台。软件及 RAM 回读不能证明光学观感或续航。
