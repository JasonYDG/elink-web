# V1.2.1 修复与交付

适用本次 DA14585 五测试点、IL3897 黑白红 250×122 标签。应用 60024 字节，完整 SPI 241664 字节，固件 ID **90559ec8**。应用 SHA256：c09c7a8fd92eea6776223cf8982dedcf82329d36aadae4688d09bfd5b773b527。

- 广播名称使用真实 MAC 最后六位大写，如 ELINK-BWR-6B91A7；移除原程序对地址的异或。扫描响应优先于 Windows 缓存名称。
- 原生持续可连接广播间隔从 687.5ms 改为 2000ms，保留三个广播频道、原生 extended sleep、每次操作后断开及 LED 唤醒关闭钩子。已有时钟刷新设置不自动改变。
- 从时钟切换其他页面，以及累计快刷后的完整刷新，先发送白色清屏，再发送目标三色页面。两次 BUSY 完成才递增一次显示代次；目标像素 RAM 保留，清屏失败不虚报完成。各阶段仍有约 90 秒 BUSY 超时，后台等待最多 190 秒。静态日历跨日仍只全刷一次。
- 蓝牙图标增为 9×13 像素，与电池采用相同黑色像素笔画。日历用黑色星期栏、红色周末及今日日期，右栏显示公历年、农历月日和节气。
- 管理端采用暖象牙、橄榄和陶土配色。公告图片支持铺满裁切、完整显示、缩放、拖动定位以及 0/90/180/270 度旋转；原图和参数随模板保存，旧图片模板保持原拉伸行为。预览统计红色像素，提示三色全刷成本。
- 首页保留连接和省电使用提示，较长的刷新与设置说明默认折叠。具体波形、固件实现和实测项目留在文档。

通过配套 V1.2.1 管理端选择 .elink-update.json 进行 OTA。有线安装选择 -spi.bin，偏移 0，按 FLASHING.md 擦/写/Verify。完整 SPI 不能用于 OTA，不烧 OTP。

49 项完整软件回归通过；新版 MAC/广播与清屏检查在 V1.2.0 上失败，在本版通过。后端名称缓存修正另有回归。真实设备结果另记 VALIDATION_REPORT.md；像素读回及 BUSY 完成不能证明残影已经消失，电流和长时间光学效果仍待实测。
