    刷新与省电

    设置待读取

    每分钟刷新会增加屏幕驱动次数，影响屏幕寿命和待机时间。长期电池使用建议每 5 分钟或更长。

    无按键标签推荐“持续可发现”。定时开放的标签在窗口外暂时搜不到。长期电池展示推荐日历、图片，或使用默认每 5 分钟或更长的时钟更新间隔。

    刷新与设置说明

    三色图片使用全刷；时钟可选整页轻快刷，并定期全刷。换小时、日期或红色内容时全刷；从时钟切换其他页面会先清屏。分钟局刷仍为实验选项。日历只在日期变化时自动刷新。

    设置保存在管理端；标签完全断电后需重新应用。再次发送图片、选择时钟或升级固件后，管理端会应用已保存设置。屏幕独立计时；更新间隔不是蓝牙校时频率。蓝牙图标表示具有蓝牙功能，不代表正在连接；电量为电压估算，实际续航取决于刷新频率和电池。

    每台屏幕单独排队并验证；切换内嵌页面后暂停该屏幕的旧内容更新计划。
