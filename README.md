# ELINK Web 1.1.9

[打开网页](https://jasonydg.github.io/elink-web/) · [Windows 管理端 1.5.14 与固件 1.5.12](https://github.com/JasonYDG/elink-web/releases/tag/manager-v1.5.14-r2) · [完整服务端源码](windows-manager/README.md)

本版修复保存图库后核对阶段停在90%的界面：服务与控制/电量通道发现均有15秒超时，恢复连接最多三次；显示核对清单与首张画面的实际读回字节进度。图片传输完成与设备保存成功分别表示，核对不符仍为待核对，不重发播放列表、不重复上传。原始提交回执丢失的设备或Windows原因尚未证实。

先点击“搜索附近屏幕”，在浏览器选择器中选中设备，将其加入屏幕列表；搜索不会切换当前连接。在对应屏幕卡片点击“连接”或“断开”。搜索新设备不再使用已勾选屏幕的身份，也不自动填入旧屏幕 MAC；指定卡片连接时仍核对设备身份，防止操作到其他屏幕。当前版本仍按串行方式连接和操作屏幕。

可选内置图库现有35张，原编号保持。晚安睡猫、山间列车、月球小兔、林间睡狐、原17号绝顶凌云、寒梅傲雪、青山绿水、书剑山河已下架；26号登高望岳更名为绝顶凌云。旧资源继续供已保存模板使用，用户模板和屏幕离线图库不删除；已有26号模板只更新未自定义的旧默认名称。所有图片像素及固件1.5.13字节保持不变。

本版另新增8张用户题字图，编号28–35：欲穷千里目、扶摇九万里、自强不息、上下求索、任平生、斩楼兰、射天狼、挑灯看剑。原图、预览与原生帧的来源和校验见ARTWORK.json。

本版另新增8张用户题字图，编号36–43：莫愁前路、春风得意、千淘万漉、青云之志、诗酒年华、鹏程万里、报国丹心、少年壮气。原图、预览与原生帧的来源和校验见ARTWORK.json。

页面移除升级包下载链接，保留“加载在线固件”。在线升级仍必须由浏览器获取固件；公开网站及GitHub中的固件资源仍可被提取，隐藏入口不提供固件保密保护。

保存到卡槽与自动换图分别设置。自动换图默认关闭，每次打开网页都需主动勾选；开启时默认每天一张，并提示刷新耗电。读取状态只取卡槽清单和当前画面，不下载全部卡槽原图。名称匹配浏览器已有记录和内置图库，旧固件没有保存未知自定义图片的原文件名。

卡槽支持“显示此图”和“读取原图”。手动显示先复用浏览器原图，缺少时只读所选卡槽；使用现有固件的单图显示指令，停止自动轮播并保留所有图库图片。仍需蓝牙连接和一次屏幕刷新，当前固件不支持一条指令直接选择任意 Flash 卡槽。

上传保留固件逐块 Flash 读回和整图 CRC 校验，七张图仍有 224 个有序写入步骤。写入阶段的状态查询从每块两次改为每四块一次、每图末尾一次，合计由 448 次降到 63 次；相同图库继续复用，不重复传图。显示提交使用 190 秒刷新等待，其余普通传输仍为 8 秒。新流程的实机耗时待测。

2.13 寸 DA14585 红白黑墨水屏，250 × 122 原生像素。网页使用访问者本机 Web Bluetooth，数据保存在当前浏览器 IndexedDB；GitHub 不运行家庭后台或提供蓝牙适配器。

本版配合固件 1.5.13，将首次图库的 120 KiB 空白检查拆为 120 次、每次 1 KiB 的只读请求，避免在单次蓝牙命令里同步扫描完整分区。全部检查通过后才创建元数据，未知内容不会被清除。Web 1.1.3 仅延长等待仍可能出现 GATT 失败及设备重启；具体复位原因尚未由实物日志确认。

首次保存请升级测试固件 1.5.13，再使用 Web 1.1.4。固件升级必须核对目标和版本、输入 `UPDATE` 再点“确认升级”；取消不创建任务，对象或升级包变化需重新确认。已有图库保留。历史 Windows 1.5.14 二进制没有新检查协议，首次保存请用新版网页。[固件增量源码、验证和兼容说明](firmware-updates/1.5.13/README.md)。

参考 4.2 寸方案的卡槽管理方法，增加“上次读回的播放槽”：显示设备已保存槽位、CRC32 和当前槽位，未提交进度另列。网页选图是待保存草稿；读取更新状态，应用才保存。仍为 7 张、双图像区和最后提交播放列表，容量与受保护的硬件布局保持。

连接在最后一次蓝牙操作后空闲 3 分钟时释放；排队、写入、刷新及 OTA 期间不因空闲释放。空闲断开后不主动重连，下一次操作会恢复已授权设备连接，无需先点“读取状态”。有排队任务时保留原有恢复流程，失败后至少间隔 15 秒再恢复。延迟到达的旧断线事件不会清空已重建的连接，手动断开保持；恢复不重放已提交操作。电脑 Edge 的具体空闲掉线原因及实际省电效果仍需现场验证。

## 功能

- 最新固件及显示能力识别，电压、当前页面、图库配置、8000 字节 RAM 像素读回；读回不是光学拍照。
- 新版时钟、刷新策略、时区、设备月历、左图右日期的图片日历、农历、当天节气或下一节气倒计时。
- 35 张中文命名的原生三色图，上传、裁切、旋转、缩放；图片日历可左右取景。
- 图片与图片日历共用离线轮播的选图、顺序、位置、间隔。1.5.11 最多 7 张，每天一张可七天一轮；旧固件仍按 4 张上限。关闭网页后设备继续换图。
- 读取设备时恢复播放列表。新固件可只读取回未知原图，逐张校验 CRC32；修改其中一张，其余设置保留，点击应用才保存。旧固件没有原图接口时会提示升级。
- 离线提醒、星期重复、持续时间、今日任务汇总、安装读回、完成与取消。
- 串行任务、置顶进度、等待取消、历史与未知结果保护；提交中断不自动重复提交。
- 网页 OTA：直接加载在线测试固件 1.5.13，也可选择本地升级包；专用应用包校验、非活动区上传、逐字节读回、单次提交及重启版本核对。

安卓使用 Chrome；Windows 使用支持 Web Bluetooth 的 Chrome/Edge，通过 HTTPS 打开本页。选择 ELINK 开头的屏幕，并关闭其他连接端。浏览器不会提供真实硬件 MAC，web-... 是本站设备标识，可通过设备名称及手动 MAC 核对。1.5.2 的原有读取/控制保留，新增功能按能力开放。

支持长写入的连接使用 128 字节像素载荷（63 包），容量不足或旧固件回退 17 字节（471 包）。屏幕清屏和三色刷新仍需等待。OTA 先用无存储写入的请求检查 136 字节连接容量，未通过则在擦写前拒绝；只能选择 .elink-update.json，不能使用全片 SPI 镜像。

升级步骤：连接屏幕并读取状态，只选择一台；在“蓝牙固件升级”点击“加载在线固件 1.5.13”，验证通过后点击“开始蓝牙 OTA”。核对设备及版本，输入 `UPDATE` 并点击“确认升级”后才会提交任务。保持供电、网页前台及蓝牙连接，等待重启版本核对完成，再保存图片。仅适用于 DA14585 五触点 250×122 黑白红屏；首次从原厂固件启用优化固件仍需原有有线安装流程。1.5.13 为候选测试固件，实物蓝牙、显示、掉电及长期稳定性待验收。旧 1.5.12 包仍保留原路径和字节。

## 数据

现有数据库名、schema、记录 ID 和历史保留，无需清空网站数据。清除数据前导出 JSON；导入前自动备份原工作区，并停止旧队列和电脑更新计划。授权不跨域，迁移后核对设备名称重新关联。电脑计划依赖页面运行，已保存的离线图库和提醒由设备执行。

旧 Windows SQLite 备份可在电脑只读转换后导入：

```powershell
python tools/convert-backup.py old-backup.sqlite3 elink-backup.json
```

## 源码、许可与检查

main 保存网页及 windows-manager/ 源码；gh-pages 只发布静态运行资源，支持 /elink-web/ 子路径。Windows 程序入口与数据路径见服务端说明。不发布本机数据库、设备 Flash 备份、凭据或私钥。

```powershell
node --test tests/*.test.js
```

图像原生帧及哈希保持不变，来源见 ARTWORK.json。通用模板使用 Noto Sans SC Black，许可见 fonts/LICENSE.txt。图片日历使用与固件同源的原生尺寸 Noto Black/Medium 和 Fusion Pixel 字形表，见 fonts/calendar-glyphs.json、fonts/FusionPixel-OFL.txt；未复制 4.2 寸固件的专有字体。

通用 Canvas 模板可能有系统栅格化差异，预制图库和日历字形不依赖系统字体。协议模拟、浏览器界面及编译检查不能代替真实手机蓝牙、实体显示、续航和掉电验收；本次为候选测试发布。


Web 1.1.5：实机发现播放列表已提交后 Windows 仍可能中止 BD03 回执。网页此时最多重连 3 次，只读核对固件、播放序号、完整配置和首张像素；不重发 BD03、不重新上传。未提交成功、目标改变、持续断线或读回不符仍保留待核对结果。


单台实机验证：本地 6B8D58 已通过 1.5.13 OTA、首次 7 张图库保存及新工作区 56,000 字节 Flash 读回；[验证范围](firmware-updates/1.5.13/PHYSICAL_VALIDATION.json)。实测为 Windows Bleak/WinRT，Edge 原生蓝牙、光学及真实掉电尚待验收。


完整图片模式实测：6B8D58 显示“长风破浪”，250×122 全部 8000 字节重连读回一致；用户确认“画面正常”。原有 7 张离线图库保留，轮播暂停。仅此一块屏幕验证，传输使用 Windows Bleak/WinRT。
