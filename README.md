# ELINK Web

独立的 2.13 寸红白黑墨水屏网页控制器。静态 HTML、CSS、JavaScript，使用访问者手机或电脑的 Web Bluetooth；不连接家庭后台，不使用服务器蓝牙。现有 Windows 集成版本继续保留。

安卓使用最新版 Chrome，通过 HTTPS 打开网页，选择 `ELINK-` 开头的设备。设备须已刷入支持 ELK1 的固件；图片、月历、新版时钟和提醒依设备能力开放。普通 iPhone Safari 不支持此蓝牙接口。

## 使用

1. 点击「连接屏幕」，在浏览器选择身边的屏幕，等待状态读取完成。
2. 首页内置 16 张 250 × 122 原生红白黑图。点图直接发送到所选屏幕，使用预制的 8000 字节画面，不重采样、不裁剪、不抖色。
3. 自己的照片到「图片」上传和裁剪，预览与发送共用同一帧。原图和裁切位置保存在浏览器。
4. 选择时钟、日历或今日任务汇总，调整参数后使用屏幕页底部的「应用到所选屏幕」。默认整页快刷，60 次后全刷；换小时、日期、红色内容或页面时，固件可能提前全刷以清除残影。蓝牙持续可发现。
5. 新日程提前写入屏幕 Flash，完整像素和策略读回后启用。显示「已写入屏幕」后可关闭网页；屏幕保持电池供电即可离线提醒。编辑、完成和删除同样需要连接屏幕确认。

顶部进度跟随所有页面。切换页面保留蓝牙；失联会尝试重连已授权设备。提交后丢失回执显示「结果待核对」，不自动重复提交图片。需要读取状态并查看实际屏幕。网页无法证明光学画面正确。

网页关闭、手机后台限制或锁屏会中止浏览器任务。图片更新计划只在网页打开且连接时运行；提前写入的屏幕离线提醒不受影响。本网页不擦写固件、不提供浏览器 OTA。

## 数据与备份

数据存于此站点、此浏览器的 IndexedDB，不上传 GitHub。不同浏览器、域名或设备的记录独立；清除网站数据会删除记录。导出 JSON 后可在另一浏览器导入。导入前自动保存一份原数据；旧队列与更新计划停止，设备状态重新读取，避免意外重放。历史任务保留最近 100 条，提醒引用的任务和未完成队列额外保留。

原集成服务继续使用原有数据，不会自动移走。需要迁移时，先在旧网页导出 SQLite 备份，在有 Python 的电脑执行：

```powershell
python tools/convert-backup.py old-backup.sqlite3 elink-backup.json
```

再在新网页导入 JSON。转换只读原文件，不覆盖现有输出。迁移设备仍须重新选择浏览器蓝牙授权，旧授权不跨域。先勾选导入的屏幕记录再连接；浏览器标识变更时，会核对设备名称并请求关联确认，保留原记录、设置及提醒归属。

## 发布与本地检查

无需构建或运行服务端。GitHub Pages 从 `gh-pages` 的仓库根目录发布；`main` 保存源码与测试。发布分支和交付 ZIP 仅含网页资源、说明与备份转换工具，保留 `.nojekyll`。资源均使用相对路径，支持项目子路径。

以下检查在源码目录运行，交付 ZIP 不包含测试夹具：

```powershell
node --test tests/*.test.js
python -m http.server 16666 --bind 127.0.0.1
```

本机调试使用 localhost；正式访问必须 HTTPS。不要将家庭后台数据库、账号、设备密钥、服务程序或固件私钥放进此仓库。

## 图稿与字体

前十二张沿用现有原生图库；新增「月球小兔、湖畔鸟居、鲸跃海面、林间睡狐」。新增图稿使用内置 imagegen 生成，再在定稿阶段转为 250 × 122 三色像素。生成提示及素材哈希见 `ARTWORK.json`。网页选择使用最终原生像素与预制 payload。

文字仍使用现有 Noto Sans SC Black，许可证见 `fonts/LICENSE.txt`。浏览器按相同字号、黑白阈值和版面渲染，系统 Canvas 栅格化可能与旧 Python 版本存在个别像素差异。预制图片不受此差异影响。

测试覆盖协议、数据往返、传图校验、提交后断线和提醒读回；模拟协议测试不能替代手机及实体屏幕验收。
